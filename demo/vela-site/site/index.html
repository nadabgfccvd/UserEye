How it works

From zero to first insight in ten minutes

No professional-services engagement. No 40-page YAML.

1

Install one agent

curl -sSL get.vela.io | sh — the agent auto-discovers services, runtimes and cloud resources on the host.

2

Watch your map appear

Service topology, dependencies and golden signals are generated automatically. No dashboards to build first.

3

Ask real questions

“Why did checkout get slow after Tuesday's deploy?” — Vela answers in SQL or plain English, with the trace to prove it.

# 1 — install the agent (Linux, macOS, or Docker)
$ curl -sSL https://get.vela.io | sh

# 2 — point it at your workspace
$ vela connect --workspace "acme-prod"

# 3 — that's it. query anything:
$ vela query "SELECT route, p95(duration_ms)   FROM traces WHERE service='checkout-api'   GROUP BY route ORDER BY 2 DESC"
